# Repoint the boundary rule and the stale `stages.yaml` path in `intelligence/`

## Problem

`intelligence/rules/migration.md:84` (Quality Gates) reads:

> Only `engine/pipeline/primitives/**` and `engine/pipeline/stage-logic/**` may call
> `git.*` / `PRManager.*` / `VCSPlatform.*` / `AgentRuntime.*`. `stage-logic/` files
> receive these deps via DI from `entry.ts` ...

`engine/pipeline/stage-logic/` does not exist; the layer is `engine/pipeline/composers/`,
and it makes exactly those calls today:

- `engine/pipeline/composers/aop-planner-stage.ts:79` — `deps.prManager.markProcessing`
- `engine/pipeline/composers/weekly-metrics-stage.ts:124` — `deps.prManager.markProcessing`
- `engine/pipeline/composers/pr-feedback-supervisor-stage.ts:124` — `git.commitCount`
- `engine/pipeline/composers/pr-feedback-supervisor-stage.ts:187` — `deps.git.headSha`
- `engine/pipeline/composers/discovery-iteration-stage.ts:192` — `deps.agentRuntime.run`
- `engine/pipeline/composers/closed-pr-recovery.ts:159,213` — `deps.vcs.getComments`, `vcs.getCodeReviews`

These rules sync into `AGENTS.md` / `.claude` / `.cursor` and load into every agent
run, so a reviewer or agent applying the rule verbatim reads the whole composer layer
as a P1 boundary violation and may "fix" correct code.

Separately, five places in `intelligence/` still point at `agents/workflow/stages.yaml`.
Neither `agents/` nor `engine/agents/workflow/` exists — the real path is
`engine/content/prompts/stages.yaml` (`intelligence/rules/context.md`).

## Solution

1. Rewrite `intelligence/rules/migration.md:84` to name
   `engine/pipeline/composers/**` alongside `engine/pipeline/primitives/**` as the
   layers permitted to call `git.*` / `PRManager.*` / `VCSPlatform.*` / `AgentRuntime.*`,
   and change the follow-on sentence from "`stage-logic/` files receive these deps via DI"
   to "composers receive these deps via DI". Keep the rest intact: no `new` on concrete
   implementations, all other modules forbidden, `WorkspaceScope` still exclusively owns
   branch management (non-negotiable after 2026-04-13).
2. Replace `agents/workflow/stages.yaml` with `engine/content/prompts/stages.yaml` at:
   - `intelligence/rules/migration.md:95` (v4 lesson 4)
   - `intelligence/rules/typescript.md:32` (FORBIDDEN — new files under `pipeline/stages/`)
   - `intelligence/rules/typescript.md:63` (REQUIRED — stages are config, not code)
   - `intelligence/agents/operator-ts-developer.md:44`
   - `intelligence/skills/operator-migrate-next/SKILL.md:55`
3. Re-run `bash intelligence/sync/scripts/sync.sh` to regenerate the derived context.
   `.claude/` and `.cursor/` are gitignored generated outputs — never hand-edit them
   (`git-commit-conventions`: no hand-editing generated outputs).

Do not touch `docs/**`, `README.md`, `.operator/context/`, or `eslint.operator.config.js`
in this change — those are separate tasks, kept apart so each is revertible on its own.
